# Chokuto-To-Sensu

## Video Demo: https://www.youtube.com/watch?v=L1NwWu_amyw

Short Metroidvania Game set in Feudal Japan, featuring a ninja protagonist setting on to save a princess.
Features:
- Upgrade System: the player can unlock a double jump, a projectile, a projectile upgrade and a "Koimanu Attack". The Koimanu Attack consists in dropping a large Koimanu (Japanese lion-dog) statue from the sky to deal high damage to any enemy crushed by it, as well some damage to enemies hit by its shockwave. The statue fades away shortly after.
- A melee attack that can be charged by keeping the button pressed
- Two doors that are unlocked with a key and a projectile, respectively
- UIs for a title screen, a pause menu, a tutorial, a game over screen and a victory screen
- Two types of enemies to defeat
- A final boss
